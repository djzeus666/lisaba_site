# ЛИСАБА — Premium Website

Modern, empathetic website for the Cognitive and Sensory-Behavioral Development Center "LISABA".

## Stack

- **Next.js 15** (App Router)
- **React 19** + TypeScript
- **Tailwind CSS 4**
- **Framer Motion** — animations & micro-interactions
- **Montserrat** — Google Fonts

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Sticky responsive header with accessibility toggle (3 modes)
- Custom cursor on desktop
- Scroll-reveal animations
- Interactive services tabs with expandable cards
- Team cards with hover bio reveal
- Filterable pricing table
- Maternal capital visual timeline
- Contact form & Yandex Map footer

## Build

```bash
npm run build
npm start
```
